# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues.

To ensure reports reach maintainers quickly, use the "Report a vulnerability"
button under the "Security" tab of this repository. This creates a private
communication channel between you and the maintainers.

If you cannot use GitHub's vulnerability reporting workflow, email the team at
[rust@synonym.to](mailto:rust@synonym.to).

Please include the affected version or commit, the expected impact, and clear
steps to reproduce the issue. If known, include any potential mitigations.

The maintainers will acknowledge the report and work with you to understand the
issue and coordinate disclosure.
